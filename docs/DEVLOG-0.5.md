# Horizon 0.5 开发日志

0.4 → 0.5 是一个**大版本**：从「只能发文字」变成「能发图/语音、能撤回、能引用」，并加入了 HorizonID 与称号系统，界面整体换成悬浮玻璃风格。

## 一、多媒体消息

| 能力 | 说明 |
|---|---|
| 发图片 | 输入栏 📷 → 选图 → 压缩到长边 1600 → 上传私有桶 `chat-media` → 发送 |
| 发语音 | 输入栏 🎤 → 点一下录、再点停 → 自动上传发送；气泡里可播放、显示时长 |
| 大图查看 | 点缩略图进全屏：左右滑切换前后图片、双击放大、点空白/✕ 关闭、边缘右滑关闭 |
| 私有存储 | 桶 `chat-media`（私有），只有会话成员能读写；显示用 1 小时签名 URL |
| 24 小时销毁 | 数据库触发器写 `expires_at = created_at + 24h`；Edge Function `cleanup-media` + pg_cron 每 15 分钟清理 |

## 二、消息能力

| 能力 | 说明 |
|---|---|
| 撤回 | 1 小时内可撤回；私聊显示「对方撤回了一条消息」，群聊显示「XX 撤回了一条消息」 |
| 重新编辑 | 撤回后 10 分钟内在输入栏上方出现「重新编辑」 |
| 引用回复 | 长按 → 引用回复，输入栏显示引用条，气泡内显示被引用内容 |
| 长按菜单 | 复制 / 选择文本 / 转发 / 引用回复 / 撤回（仅自己的消息） |

## 三、HorizonID

| 能力 | 说明 |
|---|---|
| 分配 | 从 `100001` 起按**注册顺序**自增；老用户按 `created_at` 回填 |
| 登录 | 登录框支持「用户名 / HorizonID / 邮箱」 |
| 搜好友 | 好友页输入 ID 精确查人（RPC `find_by_horizon_id`） |
| 可见性 | 「好友」页搜索框下方开关「允许别人通过 ID 找到我」；100001 也可关闭 |

## 四、称号系统

| 能力 | 说明 |
|---|---|
| 授予 | 仅 100001：聊天页 **+** → 为用户添加称号（10 字以内） |
| 管理 | 同一面板可**查询 / 修改 / 删除**某人的全部称号 |
| 双渐变 | **称号渐变** 与 **用户名渐变** 分别设置、各自两个颜色 |
| 预览 | 授予前可展开预览，实时看到名字与称号效果 |
| 显示位置 | 聊天列表、好友列表、群成员、群聊气泡发送者、聊天页顶栏 |
| 自我选择 | 「我的 → 外观 → 称号与显示」里选显示哪个（或都不显示） |

## 五、界面

| 改动 | 说明 |
|---|---|
| Liquid Glass | 新增 `.glass` 材质：半透明 + 背景模糊 + 高光描边；用在底部标签栏、聊天顶栏、输入栏、菜单 |
| 聊天顶栏 | 拆成「圆形返回 + 玻璃标题胶囊 + 圆形 ⋮」三件套；私聊只显示名字 |
| ⋮ 菜单 | 从底部弹层改成**贴在按钮下方的浮动卡片**（搜索 / 静音 / 群信息 / 清空） |
| + 菜单 | 聊天页右上 + 改为浮动菜单（创建群聊 / 加好友群 / 为 100001 加称号） |
| 气泡 | Material You 渐变（跟随主题种子色与聊天背景） |
| 一体化 | 所有页面头部与内容同色，去掉灰块、分割线、阴影 |
| 标签栏 | 悬浮胶囊、滑动 + 回弹动效、可拖动切换（75px 吸附） |
| 图标 | 全部统一为 Ionicons，不再用 emoji 当图标 |

## 六、安装与推送

| 修复 | 说明 |
|---|---|
| 覆盖安装失败 | CI 用固定 keystore（`DEBUG_KEYSTORE_BASE64`），解决每次签名不同导致的「未安装应用」 |
| 麦克风无授权弹窗 | CI 注入 `RECORD_AUDIO` / `MODIFY_AUDIO_SETTINGS`，失败会让构建变红 |
| 更新弹窗 | 读取 GitHub Releases（含 Pre-release），显示版本 + 更新内容，可直达 APK |
| 更新推送开关 | 「我的」可关闭更新提示 |
| Maven 429 | 构建改用镜像仓库 + 超时/重试 |

## 八、已知限制

1. 语音转文字未实现（WebView 不支持 Web Speech；第三方需上传音频，与 24h 销毁冲突）
2. 群信息页「媒体 / 链接」只有空态
3. 「静音」只在本机生效，不跨设备
4. 称号删除后，被授予人若正显示该称号，会自动回落到「不显示」
5. 华为 / HarmonyOS 5+ 仍无法安装 APK
