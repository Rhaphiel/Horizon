# Horizon 0.5 开发日志

0.4 → 0.5 是一个**大版本**：从「只能发文字」变成「能发图/语音、能撤回、能引用」，并加入了 HorizonID 与称号系统，界面整体换成悬浮玻璃风格。

## 一、多媒体消息

| 能力 | 说明 |
|---|---|
| 发图片 | 输入栏 📷 → 选图 → 压缩到长边 1600 → 上传私有桶 `chat-media` → 发送 |
| 发语音 | 输入栏 🎤 → 点一下录、再点停 → 自动上传发送；气泡里可播放、显示时长 |
| 大图查看 | 点缩略图进全屏：左右滑切换前后图片、双击放大、点空白/✕ 关闭、边缘右滑关闭 |
| 私有存储 | 桶 `chat-media`（私有），只有会话成员能读写；显示用 1 小时签名 URL |
| 24 小时销毁 | 数据库触发器写 `expires_at = created_at + 24h`；Edge Function `cleanup-media` + pg_cron 每 15 分钟清理 |

## 二、消息能力

| 能力 | 说明 |
|---|---|
| 撤回 | 1 小时内可撤回；私聊显示「对方撤回了一条消息」，群聊显示「XX 撤回了一条消息」 |
| 重新编辑 | 撤回后 10 分钟内在输入栏上方出现「重新编辑」 |
| 引用回复 | 长按 → 引用回复，输入栏显示引用条，气泡内显示被引用内容 |
| 长按菜单 | 复制 / 选择文本 / 转发 / 引用回复 / 撤回（仅自己的消息） |

## 三、HorizonID

| 能力 | 说明 |
|---|---|
| 分配 | 从 `100001` 起按**注册顺序**自增；老用户按 `created_at` 回填 |
| 登录 | 登录框支持「用户名 / HorizonID / 邮箱」 |
| 搜好友 | 好友页输入 ID 精确查人（RPC `find_by_horizon_id`） |
| 可见性 | 「好友」页搜索框下方开关「允许别人通过 ID 找到我」；100001 也可关闭 |

## 四、称号系统

| 能力 | 说明 |
|---|---|
| 授予 | 仅 100001：聊天页 **+** → 为用户添加称号（10 字以内） |
| 管理 | 同一面板可**查询 / 修改 / 删除**某人的全部称号 |
| 双渐变 | **称号渐变** 与 **用户名渐变** 分别设置、各自两个颜色 |
| 预览 | 授予前可展开预览，实时看到名字与称号效果 |
| 显示位置 | 聊天列表、好友列表、群成员、群聊气泡发送者、聊天页顶栏 |
| 自我选择 | 「我的 → 外观 → 称号与显示」里选显示哪个（或都不显示） |

## 八、已知限制

1. 语音转文字未实现（WebView 不支持 Web Speech；第三方需上传音频，与 24h 销毁冲突）
2. 群信息页「媒体 / 链接」只有空态
3. 「静音」只在本机生效，不跨设备
4. 称号删除后，被授予人若正显示该称号，会自动回落到「不显示」
5. 华为 / HarmonyOS 5+ 仍无法安装 APK

### 9.1 移植过来的修正

和 0.5.0 对接时的调整：
- **静音**：0.5.0 的静音存在手机本地（`localStorage` 的 `hz:mute:<聊天 id>`），只在本机有效。改用服务器上的 `conversation_mutes`，换手机也有效，推送函数也会跳过；登录后会把本机旧的静音自动搬到服务器上。界面沿用 0.5.0 的「静音」叫法
- **聊天页**：保留 0.5.0 的玻璃输入栏、引用条、⋮ 浮动菜单；「已不是好友」的提示放在输入栏的位置；长按菜单里的「引用回复」在这种私聊里不显示；图片 / 语音没有「复制 / 选择文本」
- **好友页**：「发消息」按钮放在名字和称号的右边；**群资料页**：「静音」「查找记录」按钮改用 Ionicons
- **0014**：发消息 / 撤回的触发器加上了 `reply_to`、`reply_preview` 两列（见 9.2 第 8 项）
- **0016**：`profiles` 的列权限加上 `shown_title`、`id_searchable`（称号和 ID 开关要用）
- **CI**：0.5.0 的类型检查是「只提示、不拦截」，现在改回有错误就不出 APK（目前 0 错误）

### 9.3 看过但没改的

- **ID 查找开关只挡 App 里的搜索**：登录用户直接查 `profiles` 表仍然看得到所有人的 HorizonID（100001 的称号面板也靠这个按 ID 查人）。真要藏，得收回 `horizon_id` 列的读取权限，再把用到的地方都改成函数，改动面大；对几个人的私人 App 影响很小
- **HorizonID 回收**：注销后 ID 给下一个注册的人，别人存着的旧 ID 会指向新人。这是 0.5.0 的设计，没改
- **注销会删掉他在群里发过的消息**：`messages.sender_id` 是级联删除，和注销弹窗里「聊天数据会被删除」一致，没改
- **任何人都能注册**：Supabase 后台的开关（Authentication → Sign In / Providers → Allow new users to sign up），三个人都注册好之后去关掉
- **同一个聊天的成员看得到彼此的已读时间**（`last_read_at`）：「另一台设备读过」的同步靠这一列
- **主包 1.4MB**：页面早就按需加载，剩下的是 @ionic/core 和 supabase-js；APK 从本地加载，拆开也不会更快

**验证**：`vue-tsc` 0 错误；`vite build` 通过，产物里的版本是 0.5.1；四个函数 esbuild 语法检查通过（没做 Deno 类型检查），`delete-account` 的登录方式判断单独测过 7 种 token。PGlite 里全部 24 个 migration 跑两遍（幂等），行为测试 122 项全部通过：原来的 83 项 + 新增 39 项（引用摘要由服务器生成、不能跨聊天引用、撤回后引用变「[已撤回]」；不能直接改用户名 / 账号名 / HorizonID，改名和设账号名的函数照常；只能显示自己的称号；没登录读不到 `profile_titles`、调不了 `find_for_login` / `find_by_horizon_id`；注销后群还在、群主转给最早入群的人、私聊一起删、另一方收到事件、只剩自己的群跟着删；100001 不进回收池、新注册的人拿不到 100001 也发不了称号）。拿掉 0018 重跑时，其中 11 项失败，说明测试确实测到了这些问题。
