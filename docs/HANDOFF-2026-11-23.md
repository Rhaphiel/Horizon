## 2. 昨天做了哪些改动（按主题）

### 2.1 底部标签栏（TabsPage.vue）

- 变成**悬浮胶囊**：高 62px、左右各留 20px、圆角 31px、阴影 `0 8px 24px rgba(17,24,39,.16)`。
- 选中项是一个**单独的蓝色胶囊**（`.pill`），用 `getBoundingClientRect` 量出当前标签里 `.ind` 的位置，然后 `transform: translate(...)` 移过去；宽度/高度也一起过渡。
- 动效：`.28s cubic-bezier(.3,1.15,.5,1)`（略带回弹，过冲约 15%）。
- **拖动**：按住当前选中的胶囊左右拖，松手时算胶囊中心与各标签中心的距离，**≤75px 才算吸附**并切页；否则弹回。
- **切换标签用 `router.replace`**，不是 `push`。原因：每次 push 都会在历史里堆一条，返回键就会“回到上一个标签页”。
- 拖动结束会 `suppressClickUntil` 500ms，拦掉 Ionic 按钮自带的 click，防止跳回按下时的那个标签。

### 2.2 搜索（ChatsPage.vue）

- 搜索框是胶囊（46px 高），点它进入搜索态。
- 搜索态头部：`←` + 胶囊输入框 + `取消`。
- 结果**按会话聚合**：头像 + 会话名 + `N 条相关聊天记录` + `›`。
- 点某个会话 → 二级页：会话头像/名字 + `相关聊天记录`，逐条显示发送者头像、名字、时间、命中片段（关键词高亮）。
- 点某条消息 → 进聊天并定位到那条（`openChat(cid, { msg, at })`）。
- 数据来源 `searchMessages()`（Supabase 全文检索，最多 50 条）。

### 2.3 好友页（FriendsPage.vue）

- 好友行**去掉了 `button` 和 `@click`** —— 点整行没反应，不能从好友页直接开聊（用户明确要求）。
- 保留三个可折叠分组（新朋友 / 我的好友 / 已发出的申请），每行显示自定义头像。

### 2.5 头像系统（新增）

**流程**：选图 → 校验静态图 → 圆形裁剪 → 压缩 → 上传 Storage → 写回数据库。

| 环节 | 实现 |
|---|---|
| 选图 | `<input accept="image/jpeg,image/png,image/webp">`；`isStaticImage()` 拦截视频和 GIF（黑名单式：拒 `video/*`、`image/gif`，其余 `image/*` 放行，类型为空时看扩展名） |
| 裁剪 | `AvatarCropper.vue`：`Teleport to="body"`、圆形取景、拖动/滚轮/双指/滑杆（1–4×）、导出 512×512 JPEG（q=0.9） |
| 初始比例 | `stage / min(宽,高)` —— **铺满圆形**，不会出现黑边 |
| 上传 | `{uid}/avatar-<ts>.jpg`（个人）、`{uid}/group-<cid>-<ts>.jpg`（群） |
| 写库 | `profiles.avatar_url` / `conversations.avatar_url` |
| 显示 | 聊天列表、好友列表、聊天页顶部、群信息页都走 `avatarOf(uid)` / `chat.avatarUrl` |

### 2.6 新版本弹窗（updates.ts + UpdateModal.vue）

### 2.7 登录页（LoginPage.vue）

- 密码框提示：登录时显示「密码」，注册时显示「密码（至少 6 位）」（`:label="mode === 'login' ? '密码' : '密码（至少 6 位）'"`）。
- 新增「眼睛」按钮：`type` 在 `password` / `text` 之间切换，图标 `eye` / `eyeOff`。

### 2.8 全局视觉统一（theme/m3.css）

目标：所有页面（聊天/好友/我的/外观/群信息）像一块整版，没有灰块、没有分割线。

关键就是这几条（**必须带 `!important`**，否则被 Ionic 默认样式盖掉）：

```css
ion-searchbar { background: transparent !important; box-shadow: none !important; --box-shadow: none !important; }
ion-header, ion-toolbar { box-shadow: none !important; border: 0 !important; --border-width: 0 !important; }
ion-header::after, ion-header::before, ion-toolbar::after, ion-toolbar::before { display: none !important; }
ion-content { --background: var(--md-surface); }
```

### 2.9 返回逻辑（router/index.ts + services/navigation.ts）

- `openChat(cid, query)` 会先 `router.replace(from)` 把历史归一化，再 `push /chat/:id?from=...`。
- 新增路由守卫：**从 `/chat/*` 离开到 `/tabs/*` 时，强制回到 `from` 指定的标签**（不管历史里残留的是哪个标签）。
- 例外：显式跳聊天列表的场合带 `?force=1`（例如解散群、被移出、清空后），守卫放行。

## 4. 踩过的坑（重要，按严重程度）

1. **Ionic 的全局 `img{max-width:100%}` 会把裁剪器里放大的图横向压扁**
   `node_modules/@ionic/core/css/normalize.css` 里有这条规则；裁剪图用内联 width/height 撑大，于是宽度被压回容器、高度不变 → 看起来“横向收缩”。
   **解法**：`.pic { max-width: none; max-height: none; }`

2. **`/releases/latest` 会跳过 Pre-release**
   我们的版本都勾了 Pre-release，用 latest 接口拿到 404 → 永不弹窗。
   **解法**：用 `GET /releases?per_page=10`，自己跳过 `draft`、取版本号最大的。

3. **Supabase 表能读不代表能写**
   RLS 策略和 GRANT 是两件事。改 `profiles` 时报 `permission denied for table profiles`（42501），
   **解法**：`grant select, update on public.profiles to authenticated;` + UPDATE 策略。

4. **用匿名 key 查 storage 桶列表会得到 `[]`**
   这不代表桶不存在（anon 没权限列桶），会误判。
   **解法**：以 Dashboard → Storage 或 `select * from storage.buckets`（SQL Editor）为准。

5. **`position: fixed` 在 `ion-content` 里会被滚动的“变换上下文”框住**
   裁剪层顶栏（含「完成」）会被推出可视区，桌面端尤其明显。
   **解法**：`<Teleport to="body">` + `z-index: 9999`。

6. **标签页用 `push` 会污染历史**
   返回键会“回到上一个标签”。**解法**：标签切换一律 `router.replace`。

7. **`ion-searchbar` 宿主自带底色和阴影**
   只改 `--background` 不够，会剩下一圈灰块 + 底部阴影。
   **解法**：宿主 `background: transparent !important; box-shadow: none !important;`。

8. **Windows 上 `npm.ps1` 被策略禁止**
   用 `npm.cmd`，或 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。

9. **PowerShell 5.1 不支持 `if` 作表达式**，且中文 heredoc 容易乱码
   批量改代码时优先用编辑工具（精确字符串替换），别用一大段中文 here-string。

10. **Vite dev server 运行时会锁文件**
    大改之前先停（`Get-NetTCPConnection -LocalPort 5173` 找到 PID 再 Stop-Process），否则写文件报 `ReplaceFileW EIO (Win32 32)`。

11. **Android 相册返回的 MIME 很脏**（空字符串、`image/jpg`、`image/heic`）
    严格白名单会误杀正常照片。**解法**：黑名单判断（只拒视频和 GIF），解码失败再提示换图。
