# 不能删的东西（项目内）

以后任何“清理”操作，先看这份清单。

## 🔴 绝对不要删

| 路径 | 为什么 |
|---|---|
| `releases/` | 历史 APK 归档，回滚用 |
| `docs/` | 所有设计/交接/迁移文档 |
| `tools/horizon-debug.keystore` + `.b64` | APK 签名密钥，丢了以后所有用户都必须卸载重装 |
| `tools/push-secret.txt` | 推送 Webhook 密钥 |
| `google-services.json` | Firebase 客户端配置，打 APK 必需 |
| `service-account.json` | Firebase 服务账号，部署推送函数必需 |
| `supabase/migrations/202611220002_push_trigger.sql` | 含真实 Webhook 密钥（已 gitignore） |
| `src/` `supabase/` `.github/` | 代码本体 |

## 🟡 可以删（随时能重建）

| 路径 | 重建方式 |
|---|---|
| `dist/` | `npm run build` |
| `node_modules/` | `npm install` |
| `Horizon-x.y.z-upload/` | 由 zip 解压出来的临时目录 |
| `*.log` | 日志，已经在写 `D:\Horizon-logs\` |
| `Horizon-x.y.z-upload.zip` | 旧的可以删，**只保留最新一个** |

## 🟢 建议保留（占空间但有用）

| 路径 | 说明 |
|---|---|
| `D:\Horizon-0.5.0-backup` | 0.5.0 全量备份（含 releases），确认新版稳定后可删 |
| `D:\_inspect` | 从别人 zip 解出来的参考副本，可删 |
