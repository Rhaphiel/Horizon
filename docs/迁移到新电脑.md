# 迁移到另一台电脑

这个压缩包是 **完整工作副本**（含运行所需的密钥），换电脑后按下面 4 步就能继续开发 / 打包。

## 0. 包里有什么

```
src/                   源码（Vue 3 + Ionic + TypeScript）
supabase/              数据库迁移 + Edge Functions（push-message / login-by-username）
docs/                  开发日志、文案索引、推送文档、本文件
tools/                 含 push-secret.txt（webhook 密钥）与 4 个脚本
.github/               打包流水线 build-apk.yml
dist/                  最近一次构建产物（可直接预览，也可删）
google-services.json   Firebase 配置（打 APK 必需）
service-account.json   Firebase 服务账号（部署推送函数必需）
package.json / package-lock.json / tsconfig.json / vite.config.ts / capacitor.config.json
README.md / .gitignore / .env.example / env.d.ts / index.html
```

**没有包含**：`node_modules/`（换机器要重装）、`releases/`（历史 APK，53 MB）、`android/`（由 Capacitor 生成）、各种 `.zip`。

## 1. 装 Node.js

需要 **Node 20 或更高**（当前机器是 v26）。

```powershell
# 装完重开终端验证
node -v
```

> 如果提示 `npm.ps1 无法加载，因为禁止运行脚本`：
> 用 `npm.cmd`，或执行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。

## 2. 装依赖

```powershell
cd <解压后的目录>
npm install
```

## 3. 跑起来

```powershell
npm run dev        # http://localhost:5173
npm run typecheck  # 类型检查
npm run build      # 构建到 dist/
```

手机同一 Wi-Fi 下访问 `http://<电脑局域网IP>:5173/` 预览。

## 4. 继续发版

推送到 GitHub `main` → Actions 自动出 APK。仓库 Secret 已有 `GOOGLE_SERVICES_JSON_BASE64`，不需要重配。
