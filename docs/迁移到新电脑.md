# 迁移到另一台电脑（Horizon 0.4.5）

这个压缩包是 **完整工作副本**，含源码、数据库脚本、构建流水线、以及运行/发版所需的密钥文件。换电脑后照下面做即可。

## 0. 包里有什么

```
src/                     全部源码（Vue 3 + Ionic + TS）
supabase/
  migrations/            10 个 SQL（按文件名顺序执行，全部幂等）
  functions/             push-message / login-by-username / cleanup-media
  templates/             webhook、清理定时任务模板
docs/                    DEVLOG 0.1–0.4、文案索引、交接说明、本文件
tools/                   4 个脚本 + push-secret.txt + horizon-debug.keystore(.b64)
.github/workflows/       build-apk.yml（自动出 APK）
dist/                    最近一次构建产物
google-services.json     Firebase 客户端配置（打 APK 必需）
service-account.json     Firebase 服务账号（部署推送函数必需）
package.json / package-lock.json / tsconfig.json / vite.config.ts / capacitor.config.json
README.md / .gitignore / .env.example / env.d.ts / index.html
```

**不含**：`node_modules/`（重装）、`releases/`（历史 APK 53 MB）、`android/`（Capacitor 生成）、各种 `.zip`。

## 3. 发版（GitHub Actions）

推送 `main` 后自动构建 APK。仓库需要两个 Secret：

| Secret | 用途 | 本包里对应文件 |
|---|---|---|
| `GOOGLE_SERVICES_JSON_BASE64` | Firebase 客户端配置 | `google-services.json` → base64 |
| `DEBUG_KEYSTORE_BASE64` | **固定 APK 签名**（不加会导致每次装新版提示「未安装应用」） | `tools/horizon-debug.keystore.b64` |

```powershell
# 生成 Firebase 配置的 base64
[Convert]::ToBase64String([IO.File]::ReadAllBytes('google-services.json'))
# 签名密钥的 base64 已经生成好了
Get-Content tools\horizon-debug.keystore.b64 -Raw
```

> 签名别名 `androiddebugkey`、密码 `android`（Android 调试默认值，Gradle 自动使用）。
> 指纹 SHA1：`E2:2E:18:08:08:67:91:18:CB:14:33:56:C2:DE:51:44:95:F1:2B:CC`

## 6. 24 小时清理定时任务（可选）

把 `supabase/templates/media-cleanup-cron.sql.example` 里的 `<SERVICE_ROLE_KEY>` 换成
Dashboard → Project Settings → API → `service_role` 的 JWT，然后执行。

- 每 15 分钟跑一次 `cleanup-media`
- 不配也能用，只是过期文件会一直占空间
- 验证：`select status_code, content from net._http_response order by created desc limit 3;`

## 7. 常见坑（血泪版）

| 现象 | 原因 | 处理 |
|---|---|---|
| `permission denied for table profiles` | 只有 RLS 没有 GRANT | 执行 `202611230003` |
| `operator does not exist: text = uuid` | storage 的 `owner_id` 是 text | 已修：`auth.uid()::text` |
| 装新版提示「未安装应用」 | 每次 CI 生成不同 debug 签名 | 配 `DEBUG_KEYSTORE_BASE64`，并卸载重装一次 |
| 录音直接 `Permission denied` | manifest 缺 `RECORD_AUDIO` | 已修：CI 用 Python 注入，失败会红 |
| 头像/图片被横向压扁 | Ionic 全局 `img{max-width:100%}` | `.pic { max-width: none }` |
| 提示 npm.ps1 被禁止 | 执行策略 | 用 `npm.cmd` |
| `supabase` 不是命令 | CLI 在 `D:\tools` 不在 PATH | 第 5 节两条命令 |
